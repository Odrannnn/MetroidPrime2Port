This is an early release. Please report what you hit and attach the log (F1 > System > Log).

**You need your own disc image:** Metroid Prime 2: Echoes USA (`G2ME01`), PAL (`G2MP01`), or Trilogy (`R3ME01` USA, `R3MP01` PAL). No disc image or game assets are included.

## What changed

- **Seamless item pickups has a Repeats only mode** (F1 > Enhancements > Pace): the first pickup of each kind keeps its message box, and later ones (a second Missile Expansion, Energy Tank...) show as a HUD memo. In All mode, map stations' message boxes become HUD memos too.
- **Beam switch speed** (Enhancements > Pace, 100-400%): changes beams faster.
- **Arm cannon FOV** (Video > HUD and view): the arm cannon keeps its size at a wider field of view, or follows it with Arm cannon follows FOV.
- **A Toggle lock-on lets go when its target dies** instead of orbiting the empty spot.
- **Twin-stick aim follows the game's Reverse Y Axis option.** #72
- **Cutscene audio no longer crackles or cuts out.** Thanks to rivyr. #70
- **Steam Input layouts apply** on systems that set Wayland first in SDL_VIDEODRIVER. #69
- **The mouse cursor shows on the pause and map screens** while mouse aim is on.
- **A save state made on another disc version is refused** instead of loading broken (it killed Samus on PAL). #68
- **Dark Troopers loaded from a save state are solid again** and the battle music keeps playing. #74
- **Android: Replace disc image takes effect** on the next start, such as switching to a Trilogy image. #76
- **Android: moving the data folder to shared storage continues by itself** after granting All files access, and data left in app storage no longer shows as moved. The data folder panel can also copy the shader cache out, so it can be attached to a report.
- **Fewer stutters on first play:** the shader cache now covers fights and bosses in all four worlds, and lit surfaces compile at startup. #44
